## 📌 Project Overview

Customer churn is one of the most important challenges for financial institutions because retaining existing customers is often more valuable than acquiring new ones.

This project analyzes a **Bank CRM customer dataset** using **SQL and Microsoft Power BI** to understand:

- Who is leaving the bank?
- Which customer segments have the highest churn?
- How does churn vary by geography?
- Does credit score influence customer exit behavior?
- Are inactive members more likely to churn?
- What role do gender, age, balance, salary, products, and credit-card ownership play?
- What customer characteristics could help identify potential churn risks?

The final result is an **interactive Power BI dashboard** designed to transform raw CRM data into actionable customer-risk insights.

# 📊 Dataset Overview

The dataset contains information about **10,000 bank customers**.

### Main Dataset Fields

| Column | Description |
|---|---|
| `CustomerId` | Unique customer identifier |
| `CreditScore` | Customer credit score |
| `Geography` | Customer country |
| `Gender` | Customer gender |
| `Age` | Customer age |
| `Tenure` | Number of years with the bank |
| `Balance` | Customer account balance |
| `NumOfProducts` | Number of banking products |
| `HasCrCard` | Whether customer owns a credit card |
| `IsActiveMember` | Whether customer is an active member |
| `EstimatedSalary` | Estimated customer salary |
| `Exited` | Customer churn / exit status |
